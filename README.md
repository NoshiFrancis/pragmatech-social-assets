# Pragmatech social assets

Published images for the Pragmatech social campaign. This repository exists so
Buffer can fetch post images by URL — its API accepts `assets: [{ image: { url } }]`
and has no upload endpoint, so the files have to be publicly reachable.

Marketing material only. No source, no credentials, nothing private.

Generated by the `pragmatech-social` skill; the sources live outside this repo.
